# Finjourney

**Finjourney** is a cross-platform mobile app built with React Native designed to help college students manage their finances while making budgeting engaging and social. The app allows students to set financial goals, track spending, and either compete or collaborate with friends to achieve milestones. By gamifying budgeting, Finjourney turns financial management into a motivating and interactive experience.  

---

## Features

- 🎯 **Goal Setting & Tracking** – Users can set personal savings or spending goals and monitor their progress in real-time.  
- 🤝 **Social Collaboration & Competition** – Students can create groups with friends to compete or collaborate on achieving financial goals.  
- 🏆 **Rewards & Incentives** – Integration with local businesses allows users to earn discounts or rewards for reaching their goals.  
- 📊 **Analytics & Insights** – Interactive dashboards provide a clear overview of spending habits, helping users make smarter financial decisions.  
- 🌐 **Cross-Platform Support** – Available on both iOS and Android through React Native, making it accessible to all students.
